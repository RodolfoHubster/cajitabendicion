# Cajita Bendición

Esqueleto inicial de una app web para citas de un banco de alimentos comunitario.

## Requisitos
- Node.js 20+
- npm

## Ejecutar
```bash
npm install
npm run dev
```

## Variables de entorno
Copia `.env.example` a `.env` y completa:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

## Build
```bash
npm run build
```
