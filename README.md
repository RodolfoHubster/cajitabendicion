# cajitabendicion

Aplicación web base para el sistema de citas del banco de alimentos comunitario.

## Requisitos
- Node.js 20+
- npm

## Ejecutar en local
1. Copia variables de entorno:
   - `cp .env.example .env`
2. Instala dependencias:
   - `npm install`
3. Inicia entorno de desarrollo:
   - `npm run dev`

## Scripts
- `npm run dev` inicia Vite
- `npm run build` genera build de producción
- `npm run lint` ejecuta lint
